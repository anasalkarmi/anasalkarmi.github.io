Anas Alkarmi website

Upload this whole folder to your web host (index.html at the top level).

Editing without code:
1. Open the live site with ?edit at the end of the address, for example https://anasalkarmi.co.uk/?edit
2. Press "Edit site". Click any text to change it, click a photo or video to replace it, and use the Projects,
   Design wall, Clients, Kit, Credits, Set frames and Contact tabs for the lists.
3. Press "Save (download)". You get site-update.zip. Unzip it into this folder so content.json and the new files
   in the u/ folder replace the old ones, then upload the folder again.

The site must be opened through a web address (http or https), not by double-clicking index.html,
or the editor and the 3D set cannot load their files.

People in the 3D set: Microsoft Rocketbox avatar library, MIT licence.
